# InnerWarden for OpenClaw: this skill has moved

This repository held an early (March 2026) InnerWarden skill for OpenClaw. It
is no longer maintained: its text described InnerWarden in terms that are not
true today, and its install command pointed at a release that no longer
exists. That text has been removed.

The maintained skill is
**[InnerWarden/innerwarden-skill](https://github.com/InnerWarden/innerwarden-skill)**.
For OpenClaw it is published on ClawHub as `innerwarden-security`. From
OpenClaw's workspace folder:

```sh
npx clawhub install @maiconburn/innerwarden-security
```

What it does with OpenClaw, and its limits:
[docs/openclaw.md](https://github.com/InnerWarden/innerwarden-skill/blob/master/docs/openclaw.md).
